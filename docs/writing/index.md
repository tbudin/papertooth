# Writing

*papertooth · Paper and writing*

Typed or handwritten, in ribbon, pen or pencil. The texture varies the ink a little from letter to letter.

## Parameters

| Setting | Default | Values |
|---|---|---|
| `.pt-wobble` |  | Each letter lands slightly differently, like a typewriter key |
| `.pt-mode-hand` |  | Handwriting instead of typing, on any ancestor |
| `.pt-pen-text, .pt-pencil-text, .pt-note` |  | Written with the fountain pen, a graphite pencil or the coloured pencil |
| `.pt-texture-light, .pt-texture-off` |  | Less or no ink texture |
| `--pt-wobble` | 1 | 0 to 2 |
