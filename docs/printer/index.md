# Printer

*papertooth · Images*

The picture printed again at low resolution with real dithering, the way a Game Boy Printer or a thermal receipt printer would. The ink sits straight on the page.

## Parameters

| Setting | Default | Values |
|---|---|---|
| `data-printer` | thermal | gameboy, thermal |
| `data-palette` | print | screen: the Game Boy's green |
| `data-dither` | printer default | bayer, atkinson, floyd, threshold |
| `data-dots` | 160 / 200 | Resolution across the picture |
| `--pt-print-contrast, -brightness` | 1.15, 0 |  |
| `--pt-print-wear` | .5 | Uneven heat |
| `--pt-print-ink` | #26262a | Ink colour |
