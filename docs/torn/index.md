# Torn and perforated

*papertooth · Paper goods*

A memo torn off a pad, with white fibres along the tear, and an order slip with a numbered stub.

| Setting | Default | Values |
|---|---|---|
| `.pt-torn` |  | Torn memo |
| `.pt-ticket` |  | Perforated slip |
