# Frames

*papertooth · Images*

Ways to mount a picture: an instant print, photo corners, tape or a postage stamp. Any picture works, with or without an effect.

## Parameters

| Setting | Default | Values |
|---|---|---|
| `.pt-photo[data-mount]` |  | polaroid, corners, or a .pt-tape inside |
| `--pt-photo-w` | 240px | Width |
| `--pt-photo-ratio` | 4 / 3 | Picture ratio (1 for the instant print) |
| `.pt-postage` |  | Perforated frame; wrap it in .pt-lift for a shadow |
| `--pt-perf` | 12px | Perforation pitch |
| `--pt-rot` | 0deg | Rotation |
