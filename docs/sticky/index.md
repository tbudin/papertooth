# Sticky notes

*papertooth · Paper goods*

Flat along the glue strip at the top. There is no outline: the edge you see is the shadow underneath. Four ways a note sits on a page, in the usual sizes.

## Parameters

| Setting | Default | Values |
|---|---|---|
| `data-color` | yellow | yellow, pink, mint, blue, orange |
| `data-ratio` | square | wide, tall, small, strip |
| `data-sticky` | flat | lifted, pad, stack |
| `--pt-rot` | 0deg | Rotation |
| `--pt-note-paper` |  | Any paper colour |
