# Tape

*papertooth · Paper goods*

Masking, kraft and washi tape are opaque, as they are in real life. Only clear tape lets the page through.

## Parameters

| Setting | Default | Values |
|---|---|---|
| `data-tape` | masking | masking, kraft, stripes, dots, gingham, seigaiha, clear |
| `.pt-tape--text` |  | Tape you can write on |
| `--pt-rot` | 0deg | Rotation |
