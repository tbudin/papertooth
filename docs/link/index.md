# Link underline

*papertooth · Marks*

A pen stroke under each line of a link. Hover adds a second stroke, or circles the link.

## Parameters

| Setting | Default | Values |
|---|---|---|
| `data-ul` | wobble | wobble, slant, double, swash, marker, wave, hl (highlighted; hover adds a pen underline) |
| `data-tool` | pen | ballpoint, brush, marker, graphite, pencil |
| `data-hover` | second | second (another stroke), circle, none |
| `aria-current` |  | The current page: its hover mark stays drawn (also aria-pressed, aria-expanded, aria-selected, an open <details>) |
| `aria-disabled` |  | Faded, with no hover |
| `--pt-visited` | the pen, a little darker | Colour of a visited link |
| `button.pt-link` |  | A button that reads as a link: none of the button’s own box |
| `.pt-links-mix` |  | On a container: a natural mix of styles |
