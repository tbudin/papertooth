# Cards and clips

*papertooth · Paper goods*

A ruled index card, held by tape or a paper clip. The clip sits around the paper: its inner loop disappears behind the card at the edge.

## Parameters

| Setting | Default | Values |
|---|---|---|
| `.pt-card` |  | Ruled index card |
| `.pt-clip` |  | Paper clip, placed on the top edge |
| `.pt-tape inside .pt-card` |  | Position it with top, left and --pt-rot |
