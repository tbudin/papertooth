# Checkbox and radio

*papertooth · Forms*

Hand-drawn boxes and circles over the native controls, so keyboards and screen readers work as usual.

## Parameters

| Setting | Default | Values |
|---|---|---|
| `.pt-check, .pt-radio` |  | Wrap a native input in a label |
| `data-tool` | pen | Instrument for the tick and the strike-through |
| `.pt-todo` |  | List of checkboxes on the grid |
| `data-strike` | line | line, double, scribble, under, none |
| `data-ul` | wobble | Underline style when data-strike="under" |
