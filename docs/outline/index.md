# Outlined button

*papertooth · Marks*

A drawn outline at rest, the highlighter on hover. Boxes, a loop, corners, or brackets of several kinds, including the Japanese 「」 and 【】.

## Parameters

| Setting | Default | Values |
|---|---|---|
| `data-outline` | sketch | sketch, double, broken, circled, corners, brackets, parens, braces, angles, kagi, lenticular |
| `data-tool` | ink | pen, ballpoint, brush, marker, graphite, pencil |
| `data-color` | yellow | Hover highlighter colour |
| `data-hover` | pass | pass (highlighted), underline, circle, none |
| `aria-pressed, aria-current, aria-expanded, aria-selected` |  | The button is on: its hover mark stays drawn (an open <details> too) |
| `:disabled, aria-disabled` |  | Faded, with no hover |
