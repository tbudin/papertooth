# Paper

*papertooth · Paper and writing*

Two separate choices: the paper itself (its colour and grain) and the ruling printed on it. The grid sets both the dot pitch and the line height, so text always sits on the ruling.

## Parameters

| Setting | Default | Values |
|---|---|---|
| `data-paper` | white | white, cream, washi, kraft, recycled, tracing |
| `data-ruling` | dot | dot, grid, graph, lined, blank |
| `--pt-grid` | 24px | Dot pitch and line height |
| `--pt-grain` | .1 | Grain strength (each stock has its own) |
| `--pt-dot, --pt-line` | per paper | Ruling colours; each paper sets its own |
| `.pt-guides` |  | Show the baselines |
| `.pt-desk` |  | The desk colour, on body or any container. Dark at night, unless .pt-day. |
