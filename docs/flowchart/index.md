# Flowchart

*papertooth · Diagrams*

Write a Mermaid flowchart and it is drawn by hand. Colours and fonts follow the CSS variables, so a change of pen restyles it without drawing it again.

## Parameters

| Setting | Default | Values |
|---|---|---|
| `Shapes` |  | A[rect] A(round) A([stadium]) A((circle)) A{diamond} A[[subroutine]] A[(cylinder)] A>flag] |
| `Edges` |  | --> --- -.-> ==> with |label| or -- label --> |
| `Direction` | TD | TD, LR, BT, RL |
| `data-fill` | none | wash, hatch, cross, scribble, stipple |
| `data-tool` | ink | pen, ballpoint, brush, marker, graphite, pencil, type |
| `--pt-diagram-stroke` | 1.6px | Line weight |
