# Separator

*papertooth · Marks*

A line drawn across the page, at its real width, so no two repeat.

## Parameters

| Setting | Default | Values |
|---|---|---|
| `data-rule` | wobble | wobble, double, dashes, brush, coil, scrawl, short, stars |
| `data-tool` | ribbon ink | pen, ballpoint, brush, marker, graphite, pencil |
