Bar and line chart

Mermaid's xychart syntax: hatched bars and a pen line through the points.

xychart-beta
  title "Essays published"
  x-axis [Jan, Feb, Mar, Apr, May, Jun]
  y-axis "Essays" 0 --> 8
  bar [2, 3, 5, 4, 6, 7]
  line [1, 2, 4, 4, 5, 6]
