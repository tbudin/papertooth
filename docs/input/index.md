# Text field

*papertooth · Forms*

A line on the page to write on: dotted in pencil like a printed form, inked in when you start writing. What you type is written in pen.

## Parameters

| Setting | Default | Values |
|---|---|---|
| `.pt-field` |  | Label and field together |
| `.pt-field__label` |  | Typed label above the line |
| `.pt-input` |  | Any text input, or a textarea for several ruled lines |
| `--pt-input-line` | pencil | Colour of the dotted line |
