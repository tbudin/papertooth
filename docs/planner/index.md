# Day and week

*papertooth · Planner*

A date header and a week view, Monday first. Saturday is blue and Sunday red, as on Japanese calendars. With data-today they show today.

## Parameters

| Setting | Default | Values |
|---|---|---|
| `.pt-dayhead[data-today]` |  | Filled with today by the script |
| `.pt-week[data-today]` |  | Dates for this week; today is circled |
| `kit.planner.dayHead(el, date)` |  | Any date |
