# Progress

*papertooth · Planner*

Pick the shape, then what it is filled with. A bar fills continuously; boxes and circles fill one at a time. 正 is how tallies are kept in Japan: five strokes to a character.

## Parameters

| Setting | Default | Values |
|---|---|---|
| `data-shape` | bar | bar, boxes, circles, ring, tally, sei |
| `data-style` | highlight | The fill: highlight, pencil, hatch, cross, scribble, stipple |
| `--pt-value` | .5 | 0 to 1 (or aria-valuenow) |
| `data-tool` | ink | Any instrument |
| `data-segments` | 10 | How many boxes or circles |
| `data-max` | 20 | Tally total |
| `data-label` |  | Text shown beside it, or inside the ring |
| `--pt-hl` | yellow | Highlighter colour |
