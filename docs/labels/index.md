# Labels and flags

*papertooth · Paper goods*

Printed label tape, embossed plastic labels and film flags.

## Parameters

| Setting | Default | Values |
|---|---|---|
| `.pt-label` |  | Printed label: white, yellow, clear, black |
| `.pt-label--emboss` |  | Embossed: red, blue, black, green |
| `.pt-flag` |  | Film flag: pink, yellow, mint, blue, orange |
| `.pt-tabs > .pt-tab` |  | Index tabs on the edge of a sheet |
