# Marks on text

*papertooth · Marks*

Circle, box, underline, strike or cross out a word. The teacher's hanamaru is for work well done.

## Parameters

| Setting | Default | Values |
|---|---|---|
| `data-anno` |  | circle, box, under, strike, cross, hatch, hanamaru, x |
| `data-wrap` |  | Let a longer phrase wrap: strike, under and cross follow each line; circle, box and hanamaru go around the whole phrase |
| `data-tool` | coloured pencil | pen, ballpoint, brush, marker, graphite |
| `--pt-anno` |  | Any colour |
